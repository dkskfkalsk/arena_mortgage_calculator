KB 시세 API 직접 호출 URL
주소: 경기도 수원시 권선구 곡반정동 654 수원하늘채더퍼스트2단지 제217동 제11층 제1105호
================================================================================

⚠️ 주의: 곡반정동의 정확한 법정동코드를 찾아야 합니다.

현재 데이터 파일에는 구 단위만 있어서, 곡반정동의 정확한 법정동코드를 
직접 찾아야 합니다.

================================================================================
방법 1: 코드로 자동 찾기
================================================================================

다음 명령어를 실행하세요:

python KB_api/generate_api_url.py "경기도 수원시 권선구 곡반정동 654"

또는 Python에서:

from KB_api.kb_price_api import KBPriceAPI
api = KBPriceAPI()
dongcode = api.find_dongcode("경기도 수원시 권선구 곡반정동")
print(f"법정동코드: {dongcode}")

================================================================================
방법 2: 수동으로 법정동코드 찾기
================================================================================

1. 행정표준코드관리시스템 (https://www.code.go.kr) 접속
2. "경기도 수원시 권선구 곡반정동" 검색
3. 10자리 법정동코드 확인

일반적으로 권선구의 법정동코드는 41113으로 시작합니다.
곡반정동의 법정동코드는 아마도 41113XXXXXX 형태일 것입니다.

================================================================================
방법 3: 예시 URL (권선구 - 당수동 기준)
================================================================================

아래 URL은 권선구 당수동의 법정동코드(4111314100)를 사용한 예시입니다.
곡반정동의 정확한 법정동코드로 교체해야 합니다.

https://api.kbland.kr/land-price/price/fastPriceInfo?법정동코드=4111314100&유형=1&거래유형=0

================================================================================
법정동코드를 찾은 후
================================================================================

법정동코드를 찾으면 아래 형식으로 URL을 만드세요:

https://api.kbland.kr/land-price/price/fastPriceInfo?법정동코드=[찾은법정동코드]&유형=1&거래유형=0

예시:
https://api.kbland.kr/land-price/price/fastPriceInfo?법정동코드=4111314100&유형=1&거래유형=0

로그 파일 확인
================================================================================

코드 실행 시 상세한 디버그 로그가 다음 파일에 저장됩니다:

이 파일을 확인하면 어느 단계에서 문제가 발생했는지 알 수 있습니다.
