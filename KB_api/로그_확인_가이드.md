# KB 시세 API 로그 확인

KB 시세 조회 실패·지연 시 로그를 확인하는 방법입니다.

---

## Vercel (운영)

Vercel은 파일 로그가 제한적이므로 **대시보드·CLI**를 사용합니다.

### 대시보드

1. [vercel.com](https://vercel.com) → 프로젝트
2. **Logs** 탭 또는 **Deployments** → 최신 배포 → **Functions** → `api/webhook`
3. 필터: `kb_price`, `KB 시세`, `kb-households`

### CLI

```bash
npm i -g vercel
vercel logs --follow
vercel logs --follow api/webhook
```

---

## 로컬

### 로그 파일

```
프로젝트_루트/kb_price_api_debug.log
```

### PowerShell 예시

```powershell
cd "프로젝트_루트"

# 마지막 50줄
Get-Content kb_price_api_debug.log -Tail 50

# 에러만
Select-String -Path kb_price_api_debug.log -Pattern "ERROR|❌|⚠️"

# 주소 검색
Select-String -Path kb_price_api_debug.log -Pattern "부천시"

# 실시간 tail
Get-Content kb_price_api_debug.log -Wait -Tail 20
```

---

## 로그 레벨

| 레벨 | 내용 |
|------|------|
| DEBUG | 주소 파싱, 매칭 과정 |
| INFO | 조회 시작·완료 |
| WARNING | fallback, 부분 매칭 |
| ERROR | API 실패, 데이터 없음 |

```
❌ 면적 64.08m²에 맞는 시세를 찾을 수 없음
```

## 체크리스트

1. **법정동코드** — 주소 파싱 결과, JUSO API 설정
2. **단지명** — 추출된 단지명 vs KB 단지 목록
3. **면적** — 전용/공급 구분, 허용 오차
4. **API** — URL, HTTP 상태, Vercel 60s 타임아웃
5. **세대수 Node API** — `Node kb-households API` 로그, `complex_id` 전달 여부
