# KB 시세 API 로그 확인 가이드

## 로그 확인 방법 (환경별)

### 🚀 Vercel 배포 환경

Vercel에서는 **파일 로깅이 제한적**이므로 다음 방법으로 로그를 확인하세요:

#### 1. Vercel 대시보드에서 확인 (권장)

1. **Vercel 대시보드 접속**
   - https://vercel.com 접속
   - 프로젝트 선택

2. **로그 확인 방법**
   - **Deployments** 탭 → 최신 배포 클릭
   - **Functions** 탭 → `api/webhook` 함수 클릭
   - **Logs** 탭에서 실시간 로그 확인
   
   또는
   
   - **Logs** 탭 (상단 메뉴)에서 전체 로그 확인
   - 필터링: `kb_price` 또는 `KB 시세` 검색

3. **실시간 로그 모니터링**
   - Vercel 대시보드의 **Logs** 탭에서 실시간으로 로그 확인 가능
   - 에러 발생 시 즉시 확인 가능

#### 2. Vercel CLI로 확인

```bash
# Vercel CLI 설치 (한 번만)
npm i -g vercel

# 로그 확인
vercel logs

# 특정 함수의 로그만 확인
vercel logs --follow api/webhook
```

## 로그 확인 방법

### 🚀 Vercel 환경

#### 방법 1: Vercel 대시보드 (가장 쉬운 방법)
1. https://vercel.com 접속
2. 프로젝트 선택
3. **Logs** 탭 클릭
4. 필터에서 `kb_price` 또는 `KB 시세` 검색
5. 실시간 로그 확인

#### 방법 2: Vercel CLI
```bash
# 실시간 로그 확인
vercel logs --follow

# 특정 키워드 검색
vercel logs | grep "KB 시세"
```

### 💻 로컬 환경

#### 방법 1: 파일 탐색기에서 확인
1. 프로젝트 루트 디렉토리로 이동
2. `kb_price_api_debug.log` 파일을 메모장이나 텍스트 에디터로 열기

#### 방법 2: 명령 프롬프트에서 확인
```powershell
# 프로젝트 루트 디렉토리로 이동
cd "c:\Users\박성호\Desktop\아레나홀딩스\01_프로젝트\2512_mortgage_calculator"

# 로그 파일의 마지막 50줄 확인
Get-Content kb_price_api_debug.log -Tail 50

# 로그 파일에서 에러만 확인
Select-String -Path kb_price_api_debug.log -Pattern "ERROR|❌|⚠️"

# 로그 파일에서 특정 주소 검색
Select-String -Path kb_price_api_debug.log -Pattern "부천시"
```

### 방법 3: 실시간 로그 모니터링
```powershell
# 실시간으로 로그 확인 (새로운 로그가 추가될 때마다 표시)
Get-Content kb_price_api_debug.log -Wait -Tail 20
```

## 로그 레벨 설명

로그에는 다음 레벨의 메시지가 포함됩니다:

- **DEBUG**: 상세한 디버깅 정보 (주소 파싱, 매칭 과정 등)
- **INFO**: 일반 정보 (조회 시작, 완료 등)
- **WARNING**: 경고 (매칭 실패, 대체 방법 사용 등)
- **ERROR**: 오류 (API 호출 실패, 데이터 없음 등)

## 주요 로그 패턴

### 성공적인 시세 조회
```
✅ KB 시세 조회 시작
   주소: 경기도 부천시 원미구 중동 1180-1 미리내마을...
   면적: 64.08m²
✅ 법정동코드: 4119210800
✅ 단지 목록 조회 성공: 50개 단지
✅ 단지명 부분 매칭: 미리내마을(롯데2)
✅ 면적 매칭 성공: 81.96m² (차이: 17.88m²)
✅ KB 시세 조회 완료: 55,250만원 (하한: 51,000만원)
```

### 실패 케이스
```
❌ 법정동코드를 찾을 수 없어 시세 조회 불가
⚠️ 단지명 매칭 실패, 첫 번째 단지 사용: 그린타운(금호,한양)
❌ 면적 64.08m²에 맞는 시세를 찾을 수 없음
⚠️ 사용 가능한 면적: ['120.78', '120.80', '159.49', ...]
```

## 문제 해결 체크리스트

로그 파일을 확인할 때 다음을 체크하세요:

1. **법정동코드 찾기 실패**
   - 로그에서 "❌ 법정동코드를 찾을 수 없어" 메시지 확인
   - 주소 파싱 결과 확인: `주소 파싱 결과: {...}`

2. **단지명 매칭 실패**
   - 로그에서 "⚠️ 단지명 매칭 실패" 메시지 확인
   - 추출된 단지명 확인: `✅ 주소에서 단지명 추출: ...`
   - 사용 가능한 단지 목록 확인

3. **면적 매칭 실패**
   - 로그에서 "❌ 면적 ...m²에 맞는 시세를 찾을 수 없음" 확인
   - 사용 가능한 면적 목록 확인
   - 면적 차이가 너무 큰지 확인 (전용면적 vs 공급면적)

4. **API 호출 실패**
   - 로그에서 "❌ 단지 시세 조회 실패" 또는 네트워크 오류 확인
   - API URL 확인

3. 로그 파일에서 해당 주소/면적로 검색
