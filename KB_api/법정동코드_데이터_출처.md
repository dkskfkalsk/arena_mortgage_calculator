# 법정동코드 데이터 출처

KB 시세 API가 주소 → 법정동코드 변환에 사용하는 데이터의 출처와 업데이트 방법입니다.

---

## 현재 사용 중인 데이터

| 항목 | 값 |
|------|-----|
| 런타임 파일 | `KB_api/전국_dongcode_data.json` |
| 반영일 | **2026-08-31** |
| 버전 | 2.3 |
| 동/읍/면/리 | 20,315개 |
| 이번 갱신 신규 코드 | 0개 |
| 원본 | `KB_api/260831_법정동코드 전체자료.txt` (code.go.kr 「법정동 코드전체자료」) |
| 생성 스크립트 | `KB_api/generate_dongcode_json.py` |

**런타임에는 `전국_dongcode_data.json`만 참조합니다.**  
`법정동코드 전체자료.txt`는 JSON 재생성용 원본이며, 배포·실행에 필수는 아닙니다.

---

## 공식 데이터 출처 (갱신 시)

**행정표준코드관리시스템 (code.go.kr)** — 이 프로젝트 표준 소스

| 항목 | 내용 |
|------|------|
| 다운로드 | https://www.code.go.kr/stdcode/regCodeL.do |
| 파일명 | **법정동 코드전체자료** |
| 형식 | TXT (`법정동코드` / `법정동명` / `폐지여부`) |

> 공공데이터포털 CSV·법정동 API는 형식·컬럼이 달라 `generate_dongcode_json.py`와 호환되지 않습니다. 사용하지 않습니다.

---

## 최신 데이터로 업데이트하는 방법

1. https://www.code.go.kr/stdcode/regCodeL.do 에서 **법정동 코드전체자료** 다운로드
2. 파일을 `KB_api/YYYYMMDD_법정동코드 전체자료.txt`로 저장 (날짜 접두 파일이 있으면 그걸 우선 사용)
3. 변환 실행:

```bash
python KB_api/generate_dongcode_json.py
```

4. `전국_dongcode_data.json`이 갱신됩니다. (추가항목 별도 파일은 생성하지 않음)

## 도로명주소 → 법정동코드 (보조)

동/읍/면이 없는 도로명 주소는 `전국_dongcode_data.json` 매칭 실패 시 아래 순서로 처리합니다.

1. 코드 내 하드코딩 fallback
2. **행정안전부 실시간 주소정보조회(검색API)** (JUSO)

| 항목 | 내용 |
|------|------|
| API | 행정안전부_실시간 주소정보조회(검색API) |
| 공공데이터포털 | https://www.data.go.kr/data/15057017/openapi.do |
| 승인키 신청 | https://www.juso.go.kr/addrlink/openApi/apiReqst.do |
| 엔드포인트 | https://www.juso.go.kr/addrlink/addrLinkApi.do |
| 응답 | `admCd` 10자리 = 법정동코드 |

**환경변수 (둘 중 하나):** `JUSO_API_KEY` 또는 `JUSO_CONFM_KEY`
