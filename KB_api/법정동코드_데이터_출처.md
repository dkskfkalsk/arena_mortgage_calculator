# 법정동코드 데이터 출처

KB 시세 API가 주소 → 법정동코드 변환에 사용하는 데이터의 출처와 업데이트 방법입니다.

---

## 현재 사용 중인 데이터

| 항목 | 값 |
|------|-----|
| 파일 | `KB_api/전국_dongcode_data.json` |
| 생성일 | 2025-01-23 |
| 소스 | `법정동코드 전체자료.txt` |
| 생성 스크립트 | `KB_api/generate_dongcode_json.py` |

## 공식 데이터 출처

### 1. 행정표준코드관리시스템 (code.go.kr) ⭐ 추천

**URL**: https://www.code.go.kr

#### 다운로드 방법:
1. **전체 다운로드**: https://www.code.go.kr/stdcodesrch/codeAllDownloadL.do
   - 다운로드순위에서 "법정동" 선택
   - 엑셀(XLS) 형식 제공

2. **법정동 코드 조회/다운로드**: https://www.code.go.kr/stdcode/regCodeL.do
   - "사용자 검색자료" 또는 "법정동 코드전체자료" 다운로드
   - 엑셀 형식 제공

### 2. 공공데이터포털 (data.go.kr)

#### 국토교통부_전국 법정동 (최신: 2025년 8월 7일 업데이트)
- **URL**: https://www.data.go.kr/data/15063424/fileData.do
- **형식**: CSV
- **전체 행**: 49,878개
- **데이터항목**: 
  - 법정동코드
  - 시도명
  - 시군구명
  - 읍면동명
  - 리명
  - 과거법정동코드
  - 생성일자
  - 삭제일자
- **업데이트주기**: 연간
- **다운로드**: 로그인 없이 가능

#### 국토교통부_행정구역법정동코드 (최신: 2025년 8월 7일 업데이트)
- **URL**: https://www.data.go.kr/data/15122602/fileData.do
- **형식**: CSV
- **전체 행**: 20,555개
- **데이터항목**: 
  - 행정코드
  - 행정구역명
  - 최하위행정구역명
  - 생성일자
  - 변경전행정구역코드

### 3. 오픈API (실시간 조회)

**행정안전부_행정표준코드_법정동코드 API**
- **URL**: http://apis.data.go.kr/1741000/StanReginCd/getStanReginCdList
- **형식**: JSON/XML (REST API)
- **활용신청**: 필수 (공공데이터포털에서 신청)
- **장점**: 실시간 최신 데이터 조회 가능

## 최신 데이터로 업데이트하는 방법

### 방법 1: 공공데이터포털에서 CSV 다운로드 후 변환

1. https://www.data.go.kr/data/15063424/fileData.do 접속
2. CSV 파일 다운로드
3. Python 스크립트로 JSON 변환 (기존 DongcodeJsonGenerator 사용)

### 방법 2: code.go.kr에서 엑셀 다운로드 후 변환

1. https://www.code.go.kr/stdcode/regCodeL.do 접속
2. "법정동 코드전체자료" 다운로드
3. 엑셀 파일을 JSON으로 변환

### 방법 3: API 사용 (실시간)

- 공공데이터포털에서 API 키 발급
- 실시간으로 법정동코드 조회
- 캐싱 전략 필요

## 데이터 구조 변환 필요

현재 JSON 구조:
```json
{
  "regions": {
    "경기도": {
      "districts": {
        "수원시": {
          "dongs": {
            "권선구": {
              "code": "4111314100",
              "fullName": "경기도 수원시 권선구 당수동"
            }
          }
        }
      }
    }
  }
}
```

공공데이터포털 CSV 구조:
- 법정동코드, 시도명, 시군구명, 읍면동명, 리명

## 권장 사항

1. **최신 데이터**: 공공데이터포털의 2025년 8월 7일 버전 사용
2. **업데이트 주기**: 연 1회 또는 필요시 업데이트
3. **변환 스크립트**: 기존 DongcodeJsonGenerator v2.0 스크립트 재사용 또는 수정

## 도로명주소 → 법정동코드 (도로명 자료 활용)

법정동명(동/읍/면)이 없는 **도로명 주소**(예: "경기도 김포시 양도로 161-1")는 현재 소수의 fallback 매핑으로만 처리하고 있습니다. 전국 도로명 자료를 쓰면 하드코딩 없이 전국을 커버할 수 있습니다.

### 추천: 행정안전부 도로명주소 주소DB

| 항목 | 내용 |
|------|------|
| **데이터명** | 행정안전부_도로명주소 주소DB_일간 |
| **공공데이터포털** | https://www.data.go.kr/data/15050417/fileData.do |
| **다운로드** | [주소기반산업지원서비스](http://www.juso.go.kr/externalLink/goUrl.do?menuId=DT07) (juso.go.kr → 메뉴 DT07) |
| **규모** | 약 600만 건 (시도별 구분 제공) |
| **형식** | TXT |
| **비용** | 무료, 이용허락 제한 없음 |

**표기법**: 시/도 + 시/군/구 + 읍/면 + **도로명** + 건물번호 + 상세주소 + **(참고항목)**  
**참고항목** = **법정동**, 공동주택명 → 도로명 한 건당 **법정동** 정보 포함.

### 활용 방식 (구현 시)

1. 주소DB 다운로드 후 **도로명 + 시군구** (또는 법정동) 컬럼만 추출해 **도로명→법정동코드** 매핑 테이블 생성 (CSV/JSON).
2. 기존 `전국_dongcode_data.json`으로 **법정동명 → 10자리 법정동코드** 변환은 그대로 사용.
3. `find_dongcode`에서 `parse_address`로 동/읍/면을 못 찾으면:
   - 주소에서 **도로명**(예: "양도로", "고척로") 추출 (정규식: `[가-힣]+(로|길)` 등),
   - 위 매핑 테이블로 **법정동** 조회 → 기존 법정동코드 데이터로 **법정동코드** 조회.

### 실시간 도로명주소 API (현재 적용)

동/읍/면 파싱이 실패한 **도로명 주소**는 **행정안전부 실시간 주소정보조회(검색API)** 로 법정동코드를 조회합니다.

| 항목 | 내용 |
|------|------|
| **API** | 행정안전부_실시간 주소정보조회(검색API) |
| **공공데이터포털** | https://www.data.go.kr/data/15057017/openapi.do |
| **신청/승인키** | https://www.juso.go.kr/addrlink/openApi/apiReqst.do (confmKey 발급) |
| **엔드포인트** | https://www.juso.go.kr/addrlink/addrLinkApi.do (POST) |
| **응답** | 행정구역코드(admCd) 10자리 = 법정동코드 |

**환경변수 (둘 중 하나 설정):**

- `JUSO_API_KEY` — 도로명주소 API 승인키(confmKey)
- `JUSO_CONFM_KEY` — 위와 동일 (confmKey 별칭)

설정 시 동/읍/면을 찾지 못한 주소에 대해 API로 검색해 10자리 법정동코드를 사용합니다. 미설정 시 기존 하드코딩 fallback만 사용합니다.

### 참고: 다른 도로명 관련 데이터

- **도로명주소 위치정보 요약DB** (공공데이터 15050410): 도로명+좌표. **신청서·본인인증·이용목적 심사** 필요.
- **실시간 주소 API** (15057017): 위에 적용됨. DB 다운로드 없이 요청당 조회.

### 정리

- **전국 도로명 자료를 다운로드해 두고**, 도로명→법정동(또는 법정동코드) 매핑만 만들어 두면 **하드코딩 fallback 없이** 도로명 주소를 처리할 수 있습니다.
- 시도별 파일이라 **용량·파일 개수**는 있지만, **도로명+법정동(또는 코드)** 만 남기는 전처리 스크립트를 한 번 만들어 두면, 이후에는 작은 JSON/CSV만 로드해 사용할 수 있습니다.
