# 조견 메모

금융사별 조건을 정리하는 **작업용 메모**입니다.  
공식 조견은 `data/banks/*.json`이 기준이며, 아래는 검토·메모 목적입니다.

---

## 유니온저축은행 (메모)

**선순위 가능지역**

- 서울, 경기, 인천 (수도권)
- 광역시, 세종시

---

## 조견 파일 위치

| 경로 | 설명 |
|------|------|
| `data/banks/` | 금융사별 한도·금리 JSON |
| `data/banks/refinanceable_institutions.json` | 대환 가능 기관 마스터 |
| `data/loan/` | 대출상품·팀 설정 |
