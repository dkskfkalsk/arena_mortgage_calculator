# 공공데이터포털 실거래가 API 설정 가이드

KB 시세 일반가가 없을 때, 공공데이터포털의 국토교통부 아파트 매매 실거래가를 가져와 표시하기 위한 설정 방법입니다.

---

## 1단계: 공공데이터포털 회원가입

1. **공공데이터포털** 접속: https://www.data.go.kr
2. 우측 상단 **회원가입** 클릭
3. **일반회원** 또는 **기업회원** 선택 후 가입
4. 아이디, 비밀번호, 이메일, 휴대전화 입력
5. 이메일 인증 + 휴대전화 인증 완료

---

## 2단계: 실거래가 API 활용신청

1. 로그인 후 **검색창**에 `아파트 매매 실거래가` 입력
2. **국토교통부_아파트 매매 실거래가 상세 자료** 선택  
   - 바로가기: https://www.data.go.kr/data/15126468/openapi.do
3. 상세 페이지에서 **활용신청** 버튼 클릭
4. **활용 목적** 작성 (예: "부동산 담보대출 시세 참고용 실거래가 조회")
5. **라이선스** 동의 후 신청
6. 승인 대기 (보통 **즉시~1영업일** 내 승인)

---

## 3단계: 인증키(Service Key) 발급 및 확인

1. **마이페이지** → **데이터 활용** → **Open API** → **활용신청 현황**
2. 승인된 API 목록에서 **국토교통부_아파트 매매 실거래가** 선택
3. **인증키** 또는 **일반 인증키** 버튼 클릭
4. 표시되는 **인증키 복사** (영문+숫자 조합, 길게 나옴)

> ⚠️ **주의**: 인증키는 비밀번호처럼 관리하세요. GitHub 등 공개 저장소에 올리지 마세요.

---

## 4단계: 환경변수 설정

인증키를 환경변수로 설정합니다.

### Windows (PowerShell, 현재 세션만)
```powershell
$env:REAL_ESTATE_API_KEY = "여기에_발급받은_인증키_붙여넣기"
```

### Windows (영구 설정)
1. **시작** → "환경 변수" 검색 → **시스템 환경 변수 편집**
2. **환경 변수** 버튼 클릭
3. **사용자 변수**에서 **새로 만들기**
   - 변수 이름: `REAL_ESTATE_API_KEY`
   - 변수 값: 발급받은 인증키

### .env 파일 사용 (프로젝트 루트)
```env
REAL_ESTATE_API_KEY=여기에_발급받은_인증키_붙여넣기
```
- `.env` 파일은 `.gitignore`에 추가하여 Git에 커밋되지 않도록 하세요.

## 5단계: API 사용 방법

### API 기본 정보

| 항목 | 내용 |
|------|------|
| **서비스명** | 아파트 매매 실거래가 상세 자료 |
| **요청 URL** | `http://openapi.molit.go.kr:8081/OpenAPI_ToolInstallPackage/service/rest/RTMSOBJSvc/getRTMSDataSvcAptTrade` |
| **응답 형식** | XML (또는 JSON) |
| **필수 파라미터** | serviceKey, LAWD_CD, DEAL_YMD |

### 주요 파라미터

| 파라미터 | 설명 | 예시 |
|----------|------|------|
| **serviceKey** | 공공데이터포털 인증키 | (발급받은 키) |
| **LAWD_CD** | 법정동코드 **앞 5자리** | 48310 (경남 거제시) |
| **DEAL_YMD** | 계약년월 (6자리) | 202602 (2026년 2월) |
| **pageNo** | 페이지 번호 (선택) | 1 |
| **numOfRows** | 한 페이지 건수 (선택) | 100 |

### 법정동코드 5자리 변환

- 현재 프로젝트의 `find_dongcode()`는 **10자리** 법정동코드를 반환합니다.
- 실거래가 API는 **앞 5자리**만 사용합니다.
- 예: `4831031024` → `48310`

```python
# 10자리 → 5자리 변환
dongcode_5 = dongcode_10[:5]  # "4831031024" → "48310"
```

### API 호출 예시 (Python)

```python
import requests
from urllib.parse import urlencode

# 환경변수에서 인증키 로드
import os
service_key = os.environ.get("REAL_ESTATE_API_KEY")
if not service_key:
    print("REAL_ESTATE_API_KEY 환경변수를 설정하세요.")
    exit(1)

# API URL
url = "http://openapi.molit.go.kr:8081/OpenAPI_ToolInstallPackage/service/rest/RTMSOBJSvc/getRTMSDataSvcAptTrade"

# 파라미터 (법정동코드 5자리, 최근 계약월)
params = {
    "serviceKey": service_key,
    "LAWD_CD": "48310",      # 경남 거제시
    "DEAL_YMD": "202602",    # 2026년 2월
}

resp = requests.get(url, params=params)
print(resp.text)  # XML 응답
```

## 6단계: 트래픽 및 제한사항

| 항목 | 개발계정 | 운영계정 |
|------|----------|----------|
| **일일 트래픽** | 10,000건 | 활용사례 등록 시 증가 |
| **응답 지연** | 수 초 소요 가능 | - |
| **데이터 공개** | 계약 후 약 2개월 뒤 공개 | - |

- 최근 1~2개월 실거래가는 아직 공개되지 않았을 수 있습니다.
- 계약년월을 2~3개월 전으로 설정해 조회하는 것이 안정적입니다.

---

## 7단계: 프로젝트 연동 시 참고

1. **KB 시세 조회 실패 시** (`get_kb_price` 반환값이 `None`일 때)
2. 등기부 주소로 `find_dongcode()` 호출 → 10자리 법정동코드 획득
3. 앞 5자리 추출 후 실거래가 API 호출
4. 응답에서 **아파트명** 또는 **도로명**으로 단지 매칭 (주소에서 추출한 단지명과 비교)
5. 매칭된 건 중 최근 N건(예: 3~5건)을 "1억5,000만 26.2.25 7층" 형식으로 포맷
6. `KB시세 : 없음` 옆 또는 `특이사항`에 실거래가 정보 추가
