# 공공데이터포털 실거래가 API 설정

KB 시세 일반가가 없을 때, **국토교통부 아파트 매매 실거래가**를 보조 시세로 사용하기 위한 설정 가이드입니다.

프로젝트 연동: `utils/real_transaction_api.py`  
환경변수: `REAL_ESTATE_API_KEY`

---

## 1. 공공데이터포털 회원가입

1. [data.go.kr](https://www.data.go.kr) 접속
2. **회원가입** (일반/기업)
3. 이메일·휴대폰 인증 완료

---

## 2. API 활용신청

1. 검색: `아파트 매매 실거래가`
2. **[국토교통부_아파트 매매 실거래가 상세 자료](https://www.data.go.kr/data/15126468/openapi.do)** 선택
3. **활용신청** → 목적 작성 (예: "담보대출 시세 참고용")
4. 승인 대기 (보통 즉시~1영업일)

---

## 3. 인증키 발급

1. **마이페이지** → **데이터 활용** → **Open API** → **활용신청 현황**
2. 승인된 API → **인증키** 복사

⚠️ GitHub 등 공개 저장소에 올리지 마세요.

---

## 4. 환경변수 설정

### PowerShell (현재 세션)

```powershell
$env:REAL_ESTATE_API_KEY = "발급받은_인증키"
```

### Windows 영구 / Mac·Linux

시스템 또는 사용자 환경변수 `REAL_ESTATE_API_KEY` 추가.

### `.env` (로컬)

```env
REAL_ESTATE_API_KEY=발급받은_인증키
```

Vercel/Render: 대시보드 Environment Variables에 동일 키 추가.

## 5. API 개요

| 항목 | 내용 |
|------|------|
| 서비스명 | 아파트 매매 실거래가 상세 자료 |
| 응답 | XML |
| 필수 파라미터 | `serviceKey`, `LAWD_CD`, `DEAL_YMD` |

### 주요 파라미터

| 파라미터 | 설명 | 예시 |
|----------|------|------|
| `serviceKey` | 인증키 | (발급 키) |
| `LAWD_CD` | 법정동코드 **앞 5자리** | `48310` |
| `DEAL_YMD` | 계약년월 6자리 | `202602` |

### 법정동코드 변환

프로젝트 `find_dongcode()`는 **10자리** 반환 → API는 **앞 5자리** 사용:

```python
dongcode_5 = dongcode_10[:5]  # "4831031024" → "48310"
```

---

## 6. 프로젝트 연동 흐름

1. KB 시세 조회 실패 (`get_kb_price` → `None`)
2. 등기부 주소로 법정동코드 조회
3. 5자리 추출 후 실거래가 API 호출
4. 아파트명·도로명으로 단지 매칭
5. 최근 N건을 포맷해 `특이사항` 또는 시세 보조 영역에 표시

---

## 7. 제한·주의

| 항목 | 개발계정 |
|------|----------|
| 일일 트래픽 | 10,000건 |
| 데이터 공개 | 계약 후 약 2개월 지연 |

- 최근 1~2개월은 미공개일 수 있음 → 2~3개월 전 `DEAL_YMD`로 조회 권장
- 아파트 매매만 해당 (빌라·오피스텔 등 별도 API)
