# 조회 전용 7개 스킬 법적 리스크 검토 종결

> 이 문서는 아래 7개 스킬의 현재 저장소 구현과 문서화된 사용 범위를
> 기준으로 한 내부 리스크 검토 기록이다. 개별 분쟁에 대한 법률의견서,
> 권리 비침해 보증 또는 향후 모든 변경에 대한 포괄적 승인이 아니다.

## 결론

아래 스킬은 제3자 명칭을 조회 대상이나 데이터 출처를 식별하는 데만
사용하고, 각 스킬의 `references/TRADEMARK-LEGAL-STATEMENT.md`에서
비제휴·비출처표시 원칙을 밝히고 있다.

- `kbl-results`
- `kbo-results`
- `kleague-results`
- `lotto-results`
- `kakao-map`
- `korean-transit-route`
- `delivery-tracking`

현재 기능과 아래 운영 조건이 유지되는 한, 이번 검토에서 별도의 기능
변경이나 추가 완화조치를 요구할 만한 구체적인 위법 징후는 확인되지
않았다. 따라서 기존 상표 legal statement를 유지하고, 기능 변경 없이
문서만으로 이번 법적 리스크 검토를 종결한다.

## 공통 판단

### 상표 사용

각 스킬의 명칭 사용은 k-skill 자체의 출처표시가 아니라 지원 리그,
복권 상품, API 또는 운송사를 식별하기 위한 것이다. 로고나 브랜드
디자인을 자체 표지로 사용하지 않고 공식·제휴·후원·인증을 주장하지
않는 현재 표시 방식은
[제3자 상표의 기능 설명·호환 대상 표시 검토](./trademark-use-review.md)의
판단 기준에 부합한다.

### 경기·당첨·경로 데이터

[저작권법 제91조](https://www.law.go.kr/법령/저작권법/제91조)와
[제93조](https://www.law.go.kr/법령/저작권법/제93조)는
데이터베이스제작자의 권리와 그 제한을 별도로 정한다. 현재 스킬은
날짜·회차·출발지·도착지 등 사용자의 개별 질문에 필요한 결과만
조회하여 점수, 순위, 당첨번호, 거리, 소요시간 같은 사실정보를 짧게
정리한다. 원본 데이터베이스 전체나 실질적 부분을 복제·배포하거나
독립 데이터베이스로 축적하는 기능은 제공하지 않는다.

### 공식 표면과 접근 방식

`kbl-results`, `kleague-results`, `lotto-results`, `kakao-map`,
`korean-transit-route`, `delivery-tracking`은 문서에 적힌 공식
웹/API 표면을 우선 사용한다. `kbo-results`도 날짜별 결과 조회를
제공하는 `kbo-game` 패키지의 한정된 조회 계약만 사용하고, 다른
비공식 scoreboard로 자동 우회하지 않는다.

[정보통신망 이용촉진 및 정보보호 등에 관한 법률 제48조](https://www.law.go.kr/법령/정보통신망이용촉진및정보보호등에관한법률/제48조)가
금지하는 무단 침입과 달리, 현재 흐름은 공개 조회 또는 발급받은
API 키를 이용한 통상 요청이며 인증·접근통제·CAPTCHA를 우회하지
않는다. 호출 한도와 입력 범위도 각 API가 정한 범위 안으로 제한한다.

### 개인정보 최소화

[개인정보 보호법 제3조](https://www.law.go.kr/법령/개인정보보호법/제3조)의
필요 최소한 처리 원칙에 따라 사용자 입력은 해당 조회에만 사용한다.
`lotto-results`는 사용자의 번호를 영구 저장하지 않는다.
`delivery-tracking`은 공식 운송사 표면을 사용하고, 임시 응답 파일을
삭제하며, 담당자·수취인 이름, 전화번호와 상세 메모를 결과에서
제외한다. 송장번호와 배송 결과를 별도 공개·재사용·축적하지 않는다.

| `delivery-tracking` | [#532](https://github.com/NomaDamas/k-skill/issues/532) | CJ대한통운·우체국의 공식 배송조회 표면만 사용한다. 결과를 최근 이벤트 중심으로 최소화하고 이름·전화번호·상세 메모를 제거하며 임시 파일을 삭제한다. |

## 종결 조건

다음 조건을 벗어나는 변경이 생기면 이 결론을 그대로 원용하지 않고
해당 스킬의 검토를 다시 연다.

1. 공식·공개 표면 대신 인증 또는 접근통제를 우회한다.
2. API 이용조건이나 호출량 제한을 회피한다.
3. 경기·당첨·경로·배송 데이터를 대량 수집하거나 별도 DB로 축적한다.
4. 원본 이미지, 영상, 중계, 기사, 해설 또는 상세 콘텐츠를 재배포한다.
5. 송장번호, 이동경로 또는 사용자 번호를 다른 목적으로 저장·공개한다.
6. 로고·공식·제휴·후원·인증 표현을 추가해 출처 혼동 가능성을 높인다.
7. 조회 전용 범위를 넘어 구매, 베팅, 운송계약 또는 계정 조작을 실행한다.

이 조건 아래에서는 기존 기능과 상표 legal statement 외에 별도 코드
변경, 기능 제한 또는 추가 고지는 요구하지 않는다.
